Metadata

Metadata tags live in the <head> and never render as visible page content, yet they control how a browser, search engine or social network understands and displays the page. This page's own <head> (view the page source) is used as the live example throughout.

<meta charset> — Character Encoding

Definition

Declares the character encoding of the document, almost always UTF-8, so text (including non-Latin letters) renders correctly.

Attributes

Attributes of <meta charset>
AttributeRole
charsetNames the text encoding, e.g. "UTF-8".

Example (code)

<meta charset="UTF-8">

Example (result)

Invisible, but required: it is the very first tag inside this page's own <head>.

<meta viewport> — Responsive Scaling

Definition

Tells mobile browsers to match the page's width to the device's screen width instead of zooming out to a desktop-sized layout.

Attributes

Attributes of <meta viewport>
AttributeRole
nameAlways "viewport" for this tag.
contentHolds the actual settings, e.g. "width=device-width, initial-scale=1.0".

Example (code)

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Example (result)

Invisible, but try resizing the browser window — the responsive layout on every page of this site depends on this tag.

<meta description/author/keywords> — Document Info

Definition

These <meta> variants describe the page itself: a short summary for search results, the content's author, and (historically) topical keywords.

Attributes

Attributes of these <meta> tags
AttributeRole
name="description"The summary search engines often show under the page title.
name="author"Names the document's author.
name="keywords"A comma-separated list of relevant topics (largely ignored by modern search engines, but still part of the spec).

Example (code)

<meta name="description" content="A nine-page HTML5 review site.">
<meta name="author" content="Asilbek Ermatov">
<meta name="keywords" content="HTML, HTML5, web development, lab work">

Example (result)

Invisible on the page, but present in this page's <head> — view the page source to find all three.

<title> — Document Title

Definition

Sets the text shown in the browser tab, in bookmark lists, and as the default clickable headline in search results.

Attributes

Attributes of <title>
AttributeRole
(none)<title> only contains plain text.

Example (code)

<title>HTML Review — Metadata</title>

Example (result)

Look at this page's browser tab — it reads "HTML Review — Metadata".

<link rel="stylesheet"/"icon"> — External Resources

Definition

<link> connects the document to an external resource. With rel="stylesheet" it loads CSS; with rel="icon" it sets the browser tab's favicon.

Attributes

Attributes of <link>
AttributeRole
relThe relationship to the current document, e.g. "stylesheet" or "icon".
hrefPath or URL of the linked resource.
typeThe resource's MIME type, e.g. "image/svg+xml" for an SVG favicon.

Example (code)

<link rel="stylesheet" href="css/style.css">
<link rel="icon" href="images/logo.svg" type="image/svg+xml">

Example (result)

This page's styling and the logo in its browser tab both come from these two <link> tags.

<base> — Default Relative URL

Definition

Sets a default base URL that every relative href/src in the document resolves against. At most one <base> is allowed per page.

Attributes

Attributes of <base>
AttributeRole
hrefThe base URL relative links are resolved against.
targetThe default target window/frame for every link on the page.

Example (code)

<base href="https://example.com/html-review/">

Example (result)

Not actually applied on this page, since it would redirect every relative link on this live site to example.com — shown here as a static code example only.

Open Graph Meta Tags — og:*

Definition

A property-based set of <meta> tags (the Open Graph protocol) that controls the title, description and image shown when this page is shared on social platforms like Facebook or Telegram.

Attributes

Attributes of Open Graph <meta> tags
AttributeRole
propertyThe Open Graph key, e.g. "og:title", "og:description", "og:image".
contentThe value for that key.

Example (code)

<meta property="og:title" content="HTML Review — Lab Work 3">
<meta property="og:description" content="A nine-page HTML5 review site.">
<meta property="og:image" content="images/sample.jpg">
<meta property="og:type" content="website">

Example (result)

Invisible on the page itself, but genuinely present in this page's <head> — paste this page's URL into a chat app that generates link previews to see them in action.

<script defer> — Deferred External Script

Definition

Loads an external JavaScript file in parallel with the page but delays running it until after the HTML has finished parsing, keeping first render fast and avoiding "document not ready" errors.

Attributes

Attributes of <script>
AttributeRole
srcPath or URL of the external JavaScript file.
deferRuns the script only after the HTML document has been fully parsed, in source order.

Example (code)

<script src="js/app.js" defer></script>

Example (result)
