Multimedia

Beyond plain images, HTML offers richer multimedia tags: captioned figures, responsive art direction with <picture>, embedded pages with <iframe>, scriptable drawing with <canvas>, inline vector graphics with <svg>, and the generic embedding tags <embed> / <object>.

<figure> / <figcaption> — Captioned Figure

Definition

<figure> groups self-contained content (an image, chart or code sample) together with its <figcaption>, which labels it.

Attributes

Attributes of <figure> and <figcaption>
AttributeRole
class / idOptional hooks for custom styling; neither element has unique attributes.

Example (code)

<figure>
  <img src="images/sample.png" alt="Generated sample gradient card">
  <figcaption>Figure 1 — A sample image generated with Python/Pillow.</figcaption>
</figure>

<picture> / <source> — Responsive Image

Definition

<picture> lets the browser pick among several <source> candidates (by format or screen width) before falling back to a plain <img>.

Attributes

Attributes of <picture> and <source>
AttributeRole
srcsetOn <source>, one or more candidate image files.
mediaA CSS media condition under which that source should be used.
typeThe MIME type of the candidate file, e.g. "image/svg+xml".

Example (code)

<picture>
  <source srcset="images/logo.svg" type="image/svg+xml">
  <img src="images/sample.png" alt="Sample card with vector fallback" width="200">
</picture>

<iframe> — Embedded Page

Definition

Embeds another HTML document inside the current page, in its own nested browsing context.

Attributes

Attributes of <iframe>
AttributeRole
srcThe page or URL to embed.
titleAn accessible name describing the embedded content.
width / heightSets the embedded frame's visible size.

Example (code)

<iframe src="index.html" title="Embedded preview of the Home page"
        width="100%" height="220"></iframe>

<canvas> — Scriptable Drawing Surface

Definition

Provides a blank bitmap surface that JavaScript can draw on directly — shapes, text, charts or games. By itself it is an empty rectangle.

Attributes

Attributes of <canvas>
AttributeRole
width / heightThe drawing surface's pixel dimensions.

Example (code)

<canvas id="demo-canvas" width="200" height="120"></canvas>
<script>
  const ctx = document.getElementById("demo-canvas").getContext("2d");
  ctx.fillStyle = "#2b6cb0";
  ctx.fillRect(10, 10, 80, 60);
  ctx.beginPath();
  ctx.arc(150, 60, 40, 0, Math.PI * 2);
  ctx.strokeStyle = "#ed8936";
  ctx.lineWidth = 4;
  ctx.stroke();
</script>

<svg> — Inline Vector Graphics

Definition

Embeds Scalable Vector Graphics directly in the HTML markup, describing shapes with resolution-independent, declarative tags.

Attributes

Attributes of <svg>
AttributeRole
viewBoxDefines the coordinate system used by the shapes inside.
width / heightThe rendered size of the graphic on the page.

Example (code)

<svg viewBox="0 0 100 100" width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="#2b6cb0"></circle>
  <rect x="30" y="30" width="40" height="40" fill="#ed8936"></rect>
</svg>

<embed> / <object> — Generic External Content

Definition

Both tags embed external resources handled by a plugin or the browser itself; <object> additionally supports fallback content between its tags.

Attributes

Attributes of <embed> and <object>
AttributeRole
src (embed) / data (object)The resource to embed.
typeThe resource's MIME type.

Example (code)

<embed src="images/sample.png" type="image/png" width="160">
<object data="images/sample.png" type="image/png" width="160">
  Image could not be displayed.
</object>
