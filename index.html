<!DOCTYPE html> — Document Type Declaration

Definition

The DOCTYPE declaration is not an HTML tag but an instruction that tells the browser which version of HTML the page uses. <!DOCTYPE html> declares HTML5 and must be the very first line of the document.

Attributes

Attributes of <!DOCTYPE>
AttributeRole
none (keyword "html")Signals HTML5; no further attributes are needed in modern HTML.

Example (code)

<!DOCTYPE html>
<html lang="en">
  ...
</html>

Example (result)

The declaration itself renders nothing visible — it only switches the browser into standards mode, which is why this whole page displays correctly.

<html> — Root Element

Definition

The <html> element is the root container for the entire document; every other element is nested inside it.

Attributes

Attributes of <html>
AttributeRole
langDeclares the language of the document (e.g. "en") for accessibility and search engines.
dirSets text direction, "ltr" (left-to-right) or "rtl" (right-to-left).

Example (code)

<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Example (result)

This whole web page is the rendered result of one <html> element with lang="en".

<head> — Document Metadata Container

Definition

The <head> element holds information about the page — title, character set, stylesheets, icons — that is not displayed directly in the page body.

Attributes

Attributes of <head>
AttributeRole
(none commonly used)<head> is a pure container; it takes no attributes in normal use.

Example (code)

<head>
  <meta charset="UTF-8">
  <title>HTML Review — Home</title>
  <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

Nothing is drawn on screen directly, but the browser tab title and this page's styling both come from this page's <head>.

<body> — Visible Content Container

Definition

The <body> element contains everything the visitor actually sees and interacts with: text, images, forms, and so on.

Attributes

Attributes of <body>
AttributeRole
class / idHooks used by CSS or JavaScript to style or select the whole page body.

Example (code)

<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>

Example (result)

This entire visible page — header, navigation, main content and footer — is the content of one <body> element.

<title> — Browser Tab Title

Definition

The <title> element defines the text shown in the browser tab/window and used as the default name when the page is bookmarked.

Attributes

Attributes of <title>
AttributeRole
(none)<title> only ever contains plain text; it accepts no attributes.

Example (code)

<title>HTML Review — Home</title>

Example (result)

Look at the browser tab for this page — it reads "HTML Review — Home", which is exactly this element's text.

<h1>–<h6> — Headings

Definition

Headings create a hierarchical outline of the page. <h1> is the most important (usually one per page) down to <h6>, the least important.

Attributes

Attributes of <h1>–<h6>
AttributeRole
idGives the heading a unique anchor, usable for in-page navigation like this page's table of contents.
classAllows CSS to style a particular group of headings differently.

Example (code)

<h1>Level 1</h1>
<h2>Level 2</h2>
<h3>Level 3</h3>
<h4>Level 4</h4>
<h5>Level 5</h5>
<h6>Level 6</h6>

<p> — Paragraph

Definition

The <p> element represents a block of running text — a paragraph. Browsers add space before and after it by default.

Attributes

Attributes of <p>
AttributeRole
class / idUsed to style or target a specific paragraph with CSS.

Example (code)

<p>This is a paragraph of text.</p>

Example (result)

This is a paragraph of text.

<div> — Generic Block Container

Definition

The <div> element is a block-level container with no inherent meaning; it exists purely to group content for styling or layout.

Attributes

Attributes of <div>
AttributeRole
classThe most common hook; lets CSS style every div sharing that class.
idTargets one unique div, e.g. for a page section.

Example (code)

<div class="card">
  <p>Content inside a div.</p>
</div>

Example (result)

Content inside a div.

<span> — Generic Inline Container

Definition

The <span> element is the inline counterpart of <div>: it groups a piece of text or inline content without starting a new line.

Attributes

Attributes of <span>
AttributeRole
class / idStyles or selects just the wrapped inline text, without breaking the line.

Example (code)

<p>This word is <span class="brand">highlighted</span> inline.</p>

Example (result)

This word is highlighted inline.

HTML Comments — <!-- -->

Definition

Anything written between <!-- and --> is a comment: it is ignored by the browser and never shown to visitors, but remains visible in the page source for developers.

Attributes

Attributes of HTML comments
AttributeRole
(none)Comments are not elements and cannot carry attributes.

Example (code)

<!-- This note explains the next block to other developers -->
<p>Visible text.</p>

Example (result)

Visible text. (The comment itself produced no output — view this page's source to find it right above the header.)
