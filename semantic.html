Semantic & Layout

Semantic tags describe the role of a page region instead of just its appearance. This page reviews the landmark elements (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>), small interactive/semantic tags (<details>, <time>, <address>), and finishes with a Flexbox layout built from them.

<header> — Introductory Region

Definition

Marks introductory content for a page or a section — typically a logo, site title and primary navigation, as used at the very top of this page.

Attributes

Attributes of <header>
AttributeRole
id / classUsed here as id="site-header" to style the shared banner.

Example (code)

<header id="site-header">
  <div class="brand">HTML Review</div>
  <nav>...</nav>
</header>

Example (result)

The blue banner at the top of this page is the rendered <header> element.

<nav> — Navigation Block

Definition

Marks a block of primary navigation links, helping assistive technology and search engines identify the site's main menu.

Attributes

Attributes of <nav>
AttributeRole
aria-labelGives the navigation region an accessible name, useful when a page has more than one <nav>.

Example (code)

<nav aria-label="Main navigation">
  <ul>
    <li><a href="index.html">Home</a></li>
    ...
  </ul>
</nav>

Example (result)

The menu bar inside this page's header — Home, Text, Links & Media, etc. — is the rendered <nav> element.

<main> — Primary Content

Definition

Wraps the content unique to the current page, excluding repeated elements like the header, navigation or footer. There should be only one per page.

Attributes

Attributes of <main>
AttributeRole
id / classOptional hooks for custom styling, e.g. max-width centering.

Example (code)

<main>
  <h1>Semantic & Layout</h1>
  ...
</main>

Example (result)

Everything between this page's header and footer — including this very sentence — lives inside the page's single <main> element.

<section> — Thematic Grouping

Definition

Groups related content under a common theme, usually introduced by its own heading — every gray card on this page is itself a <section class="tag-demo">.

Attributes

Attributes of <section>
AttributeRole
id / classUsed throughout this site as class="tag-demo" for consistent styling.

Example (code)

<section>
  <h2>Latest Announcements</h2>
  <p>...</p>
</section>

Example (result)

Latest Announcements

Lab Work 3 has been published to all students.

<article> — Self-contained Content

Definition

Represents content that could stand alone and be redistributed independently — a blog post, a news story, or a forum comment.

Attributes

Attributes of <article>
AttributeRole
id / classOptional hooks for custom styling.

Example (code)

<article>
  <h3>Why Semantic HTML Matters</h3>
  <p>Semantic tags improve accessibility and SEO.</p>
</article>

Example (result)

Why Semantic HTML Matters

Semantic tags improve accessibility and SEO.

<aside> — Tangentially Related Content

Definition

Marks content loosely related to the surrounding text, such as a sidebar, a pull quote, or related links.

Attributes

Attributes of <aside>
AttributeRole
id / classOptional hooks for custom styling.

Example (code)

<aside>
  <h4>Tip</h4>
  <p>Use Live Server to preview this site locally.</p>
</aside>

Example (result)

Tip

Use Live Server to preview this site locally.

<footer> — Closing Region

Definition

Marks the closing content of a page or section — typically authorship, copyright and related links, as used at the bottom of this page.

Attributes

Attributes of <footer>
AttributeRole
id / classUsed here as id="site-footer" to style the shared footer.

Example (code)

<footer id="site-footer">
  <p>Authors: ... &copy; 2026</p>
</footer>

Example (result)

The dark bar at the very bottom of this page is the rendered <footer> element.

<details> / <summary> — Disclosure Widget

Definition

Creates a native collapsible widget: <summary> is the always-visible label, and the rest of the content toggles open/closed on click — no JavaScript required.

Attributes

Attributes of <details>
AttributeRole
openRenders the widget already expanded on page load.

Example (code)

<details>
  <summary>What is Live Server?</summary>
  <p>A VS Code extension that serves static files with live reload.</p>
</details>

Example (result)

What is Live Server?

A VS Code extension that serves static files with live reload.

<time> — Machine-readable Date/Time

Definition

Marks a human-readable date or time while attaching a machine-readable value via the datetime attribute.

Attributes

Attributes of <time>
AttributeRole
datetimeThe ISO 8601 value a script or browser can parse, independent of the displayed text.

Example (code)

<p>Published on <time datetime="2026-10-02">October 2, 2026</time>.</p>

Example (result)

Published on October 2, 2026.

<address> — Contact Information

Definition

Marks the contact information for the author or owner of the document or an enclosing <article>; browsers typically italicize it.

Attributes

Attributes of <address>
AttributeRole
(none)<address> carries no unique attributes; it is a semantic grouping only.

Example (code)

<address>
  Written by Asilbek Ermatov.<br>
  Contact: <a href="mailto:example@mail.com">example@mail.com</a>
</address>

Example (result)

Written by Asilbek Ermatov.
Contact: example@mail.com

Flexbox Layout Example

Definition

Combines <aside> and <article> inside a flex container (display: flex in style.css) to build a classic two-column page layout that reflows on small screens.

Attributes

Relevant CSS, not HTML attributes
AttributeRole
display: flexTurns the wrapper into a flex container (defined on .layout-demo in style.css).
flex: 1 1 200px / 3 1 420pxGives the sidebar and the article different growth ratios and minimum widths.

Example (code)

<div class="layout-demo">
  <aside>Sidebar content</aside>
  <article>Main article content</article>
</div>

Example (result)
