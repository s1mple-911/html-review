Tables

HTML tables organize tabular data into rows and columns using <table> and its structural children — <thead>, <tbody>, <tfoot> — plus cell and grouping elements such as <colgroup>.

<table> / <caption> — Table and Its Title

Definition

The <table> element wraps an entire data table; an optional <caption> provides its title, read first by screen readers.

Attributes

Attributes of <table>
AttributeRole
class / idHooks used by CSS, e.g. to apply the striped-row styling used on this page.

Example (code)

<table>
  <caption>Weekly Study Schedule</caption>
  ...
</table>

Example (result)

See the full worked example below in the <tfoot> section — it combines <table> and <caption> with every other tag on this page.

<thead> — Table Header Group

Definition

Groups the header row(s) of a table, letting browsers (and CSS) style the heading band separately from the data.

Attributes

Attributes of <thead>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<thead>
  <tr><th>Subject</th><th>Monday</th></tr>
</thead>

Example (result)

Shown as the blue heading row of the schedule table below.

<tbody> — Table Body Group

Definition

Groups the main block of data rows, separate from the header and footer, so each part can be styled or scrolled independently.

Attributes

Attributes of <tbody>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<tbody>
  <tr><td>Math</td><td>9:00</td></tr>
</tbody>

Example (result)

Shown as the striped data rows of the schedule table below.

<tfoot> — Table Footer Group

Definition

Groups summary row(s) such as totals, shown at the bottom of the table regardless of where it is written in the HTML source.

Attributes

Attributes of <tfoot>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<table>
  <caption>Weekly Study Schedule</caption>
  <colgroup>
    <col>
    <col span="2">
  </colgroup>
  <thead>
    <tr>
      <th scope="col">Subject</th>
      <th scope="col">Monday</th>
      <th scope="col">Tuesday</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Morning</th>
      <td colspan="2">Mathematics (2 hours)</td>
    </tr>
    <tr>
      <th scope="row" rowspan="2">Afternoon</th>
      <td>Physics</td>
      <td>Chemistry</td>
    </tr>
    <tr>
      <td colspan="2">Lab session</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Total</td>
      <td colspan="2">6 hours</td>
    </tr>
  </tfoot>
</table>

Example (result)

Weekly Study Schedule
Subject Monday Tuesday
Morning Mathematics (2 hours)
Afternoon Physics Chemistry
Lab session
Total 6 hours

<tr> — Table Row

Definition

Represents one horizontal row of a table, holding a sequence of <th> and/or <td> cells.

Attributes

Attributes of <tr>
AttributeRole
class / idOptional hooks for custom styling, e.g. zebra striping.

Example (code)

<tr>
  <th scope="row">Morning</th>
  <td colspan="2">Mathematics (2 hours)</td>
</tr>

Example (result)

See the "Morning" row of the schedule table above.

<th> — Header Cell

Definition

Defines a header cell for a row or column; browsers render it bold and centered by default, and the scope attribute links it to the cells it describes.

Attributes

Attributes of <th>
AttributeRole
scope"col" if it heads a column, "row" if it heads a row — improves screen-reader navigation.

Example (code)

<th scope="col">Subject</th>

Example (result)

See the "Subject", "Monday" and "Tuesday" column headers in the schedule table above.

<td> — Data Cell

Definition

Defines an ordinary data cell inside a table row.

Attributes

Attributes of <td>
AttributeRole
colspanMakes the cell span across multiple columns.
rowspanMakes the cell span across multiple rows.

Example (code)

<td colspan="2">Mathematics (2 hours)</td>

Example (result)

See the merged "Mathematics (2 hours)" cell spanning two columns in the schedule table above.

<colgroup> / <col> — Column Grouping

Definition

<colgroup> groups one or more <col> elements so whole columns can be styled or sized at once, without touching every cell.

Attributes

Attributes of <colgroup> and <col>
AttributeRole
spanNumber of columns a single <col> should apply to.

Example (code)

<colgroup>
  <col>
  <col span="2">
</colgroup>

Example (result)

Defines the three columns of the schedule table above before any rows are drawn.
