Forms

HTML forms collect user input through <form> and a family of controls: labelled text/number/date fields, choices, files, and buttons. This page's form does not submit to a real server — action="#" is a placeholder for an academic demo.

<form> — Form Container

Definition

Wraps a group of controls that are submitted together to a server.

Attributes

Attributes of <form>
AttributeRole
actionThe URL the form data is sent to when submitted.
methodHTTP method used to send the data, typically "get" or "post".

Example (code)

<form action="#" method="get">
  ...
</form>

Example (result)

The complete form at the bottom of this page is one <form action="#" method="get"> element.

<label> — Field Label

Definition

Attaches a readable caption to a form control; clicking the label focuses or toggles the associated control.

Attributes

Attributes of <label>
AttributeRole
forMatches the id of the control it labels.

Example (code)

<label for="demo-name">Name</label>
<input id="demo-name" type="text">

Example (result)

<input> — Input Control (multiple types)

Definition

A single-line control whose behaviour depends entirely on its type attribute — text, email, password, number, date, checkbox, radio, file, range or color are shown below.

Attributes

Attributes of <input>
AttributeRole
typeSelects the control's behaviour and look (text, email, checkbox, etc.).
placeholderFaint hint text shown inside an empty field.
requiredPrevents form submission until the field has a value.

Example (code)

<input type="text" placeholder="Jane Doe" required>
<input type="email" placeholder="jane@example.com">
<input type="password" placeholder="Password">
<input type="number" min="0" max="10">
<input type="date">
<input type="checkbox" checked>
<input type="radio" name="demo-radio" checked>
<input type="file">
<input type="range" min="0" max="100">
<input type="color" value="#2b6cb0">

<textarea> — Multi-line Text

Definition

A resizable, multi-line plain-text input, useful for comments or free-form descriptions.

Attributes

Attributes of <textarea>
AttributeRole
rows / colsVisible height and width of the text area, in text lines/characters.
placeholderFaint hint text shown when the area is empty.

Example (code)

<textarea rows="3" cols="30" placeholder="Write your feedback..."></textarea>

Example (result)

<select> / <option> / <optgroup> — Drop-down List

Definition

<select> creates a drop-down of <option> choices, which can be grouped under an <optgroup> label.

Attributes

Attributes of <select>, <option>, <optgroup>
AttributeRole
nameKey the selected value is submitted under.
selectedOn an <option>, pre-selects it when the page loads.
labelOn an <optgroup>, the heading shown above its options.

Example (code)

<select name="language">
  <optgroup label="Markup">
    <option value="html" selected>HTML</option>
  </optgroup>
  <optgroup label="Programming">
    <option value="js">JavaScript</option>
    <option value="py">Python</option>
  </optgroup>
</select>

Example (result)

<button> — Button

Definition

A clickable control; its type determines whether it submits the form, resets it, or does nothing by default.

Attributes

Attributes of <button>
AttributeRole
type"submit" sends the form, "reset" clears it, "button" does nothing on its own.

Example (code)

<button type="submit">Send</button>

Example (result)

<fieldset> / <legend> — Grouped Controls

Definition

<fieldset> draws a box around a related group of controls; <legend> gives that group a caption.

Attributes

Attributes of <fieldset> and <legend>
AttributeRole
disabledOn <fieldset>, disables every control nested inside it.

Example (code)

<fieldset>
  <legend>Contact method</legend>
  <label><input type="radio" name="contact"> Email</label>
  <label><input type="radio" name="contact"> Phone</label>
</fieldset>

Full Form Example

Definition

All the controls above combined into one coherent registration form, including required and placeholder in context.

Attributes

Key attributes used together
AttributeRole
requiredBlocks submission of the Full Name and Email fields until filled in.
placeholderShows example input for Full Name and Email.

Example (code)

<form action="#" method="get">
  <fieldset>
    <legend>Workshop registration</legend>
    <label for="full-name">Full name</label>
    <input id="full-name" type="text" placeholder="Jane Doe" required>

    <label for="full-email">Email</label>
    <input id="full-email" type="email" placeholder="jane@example.com" required>

    <button type="submit">Register</button>
  </fieldset>
</form>
