Lists

HTML offers three list types: unordered (<ul>), ordered (<ol>) and description lists (<dl>). This page reviews each one, their list items, and how lists can be nested inside one another.

On this page

  1. <ul>
  2. <ol>
  3. <li>
  4. <dl> / <dt> / <dd>
  5. Nested Lists

<ul> — Unordered List

Definition

Groups a set of list items with no inherent order; browsers render each item with a bullet by default.

Attributes

Attributes of <ul>
AttributeRole
class / idHooks used by CSS to change bullet style or spacing.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Example (result)

  • HTML
  • CSS
  • JavaScript

<ol> — Ordered List

Definition

Groups list items that follow a meaningful sequence, numbered automatically by the browser.

Attributes

Attributes of <ol>
AttributeRole
typeNumbering style: "1" (default), "A", "a", "I" or "i".
startThe number the list should begin counting from.
reversedCounts the list down instead of up.

Example (code)

<ol type="A" start="3">
  <li>Third item, labeled C</li>
  <li>Fourth item, labeled D</li>
</ol>
<ol reversed>
  <li>Gold</li>
  <li>Silver</li>
  <li>Bronze</li>
</ol>

Example (result)

  1. Third item, labeled C
  2. Fourth item, labeled D
  1. Gold
  2. Silver
  3. Bronze

<li> — List Item

Definition

Represents one entry inside a <ul>, <ol> or <menu> list.

Attributes

Attributes of <li>
AttributeRole
valueInside an <ol>, overrides the automatic number for that item and all items after it.

Example (code)

<ol>
  <li value="5">Jumps to five</li>
  <li>Continues as six</li>
</ol>

Example (result)

  1. Jumps to five
  2. Continues as six

<dl> / <dt> / <dd> — Description List

Definition

A description list (<dl>) pairs terms (<dt>) with their descriptions (<dd>) — ideal for glossaries or key/value data.

Attributes

Attributes of <dl>, <dt>, <dd>
AttributeRole
class / idOptional hooks for custom styling; no element-specific attributes exist.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

Example (result)

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

Nested Lists — <ul> Inside <ol>

Definition

A list item can itself contain a whole new list, letting you build multi-level outlines such as a table of contents or a recipe with sub-steps.

Attributes

Attributes relevant to nesting
AttributeRole
(inherited)The inner list uses the same attributes (type, start, reversed, value) independently of its parent.

Example (code)

<ol>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ol>

Example (result)

  1. Frontend
    • HTML
    • CSS
  2. Backend
