Text Formatting

This page reviews the inline and block tags HTML provides for formatting text: line breaks, emphasis, highlighting, quotations and inline code. Each tag below includes a definition, its attributes, the raw code and the rendered result.

<p> — Paragraph

Definition

Defines a paragraph of text. Browsers automatically add vertical spacing before and after each paragraph.

Attributes

Attributes of <p>
AttributeRole
class / idHooks for styling an individual paragraph with CSS.

Example (code)

<p>First paragraph.</p>
<p>Second paragraph.</p>

Example (result)

First paragraph.

Second paragraph.

<br> — Line Break

Definition

Inserts a single line break inside text, without starting a new paragraph. It is a void (self-closing) element.

Attributes

Attributes of <br>
AttributeRole
(none)<br> takes no attributes; it is purely a line-break marker.

Example (code)

<p>Line one<br>Line two</p>

Example (result)

Line one
Line two

<hr> — Thematic Break

Definition

Draws a horizontal rule that marks a thematic shift between sections of content, such as a change of topic.

Attributes

Attributes of <hr>
AttributeRole
(none commonly used)<hr> is a void element styled only through CSS (e.g. border, width).

Example (code)

<p>Before the break.</p>
<hr>
<p>After the break.</p>

Example (result)

Before the break.

After the break.

<strong> — Strong Importance

Definition

Marks text as having strong importance; browsers render it bold, and assistive technology announces it with added emphasis.

Attributes

Attributes of <strong>
AttributeRole
class / idOptional hooks for custom styling beyond the default bold weight.

Example (code)

<p>This step is <strong>mandatory</strong>.</p>

Example (result)

This step is mandatory.

<em> — Emphasis

Definition

Marks text with stress emphasis; browsers render it in italics, changing the meaning of the sentence when read aloud.

Attributes

Attributes of <em>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>I <em>really</em> mean it.</p>

Example (result)

I really mean it.

<b> — Bring Attention To

Definition

Renders text in bold purely for stylistic attention (such as keywords in a review), without implying extra importance like <strong> does.

Attributes

Attributes of <b>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>The <b>keyword</b> in this sentence is bold.</p>

Example (result)

The keyword in this sentence is bold.

<i> — Idiomatic Text

Definition

Renders text in italics for an alternate voice or mood — such as foreign words or ship names — without the emphasis meaning of <em>.

Attributes

Attributes of <i>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>The term <i>habeas corpus</i> is Latin.</p>

Example (result)

The term habeas corpus is Latin.

<u> — Unarticulated Annotation

Definition

Renders text with an underline, typically used to flag a non-textual annotation such as a proper name or a misspelling.

Attributes

Attributes of <u>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>Please check the <u>underlined</u> word.</p>

Example (result)

Please check the underlined word.

<mark> — Highlighted Text

Definition

Highlights a run of text for reference, such as a search match, by giving it a yellow background by default.

Attributes

Attributes of <mark>
AttributeRole
class / idOptional hooks to change the highlight color via CSS.

Example (code)

<p>Search results for <mark>HTML</mark> found 12 pages.</p>

Example (result)

Search results for HTML found 12 pages.

<small> — Side Comment

Definition

Represents side comments such as fine print, disclaimers or copyright notices, rendered in a smaller font size.

Attributes

Attributes of <small>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>Price: $9.99 <small>(tax not included)</small></p>

Example (result)

Price: $9.99 (tax not included)

<sub> / <sup> — Subscript and Superscript

Definition

<sub> lowers text below the baseline (e.g. chemical formulas); <sup> raises it above the baseline (e.g. footnote markers or exponents).

Attributes

Attributes of <sub> and <sup>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<p>H<sub>2</sub>O and E=mc<sup>2</sup></p>

Example (result)

H2O and E=mc2

<blockquote> — Block Quotation

Definition

Marks a long quotation taken from another source as its own indented block.

Attributes

Attributes of <blockquote>
AttributeRole
citeA URL pointing to the source of the quotation.

Example (code)

<blockquote cite="https://www.w3.org/">
  The Web is more a social creation than a technical one.
</blockquote>

Example (result)

The Web is more a social creation than a technical one.

<q> — Inline Quotation

Definition

Marks a short quotation that flows inline with surrounding text; browsers automatically add quotation marks around it.

Attributes

Attributes of <q>
AttributeRole
citeA URL pointing to the source of the quotation.

Example (code)

<p>She said <q>HTML is the skeleton of the web</q>.</p>

Example (result)

She said HTML is the skeleton of the web.

<code> — Inline Code

Definition

Marks a short fragment of computer code, rendered in the browser's default monospace font.

Attributes

Attributes of <code>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

Example (result)

Use console.log() to debug.

<pre> — Preformatted Text

Definition

Preserves whitespace and line breaks exactly as written in the source; commonly paired with <code> to display multi-line code blocks.

Attributes

Attributes of <pre>
AttributeRole
class / idOptional hooks for custom styling.

Example (code)

<pre>
function greet() {
  return "Hello";
}
</pre>

Example (result)

function greet() {
  return "Hello";
}

<abbr> — Abbreviation

Definition

Marks an abbreviation or acronym; the title attribute supplies the full expansion, usually shown as a tooltip on hover.

Attributes

Attributes of <abbr>
AttributeRole
titleHolds the full, expanded form of the abbreviation.

Example (code)

<p><abbr title="HyperText Markup Language">HTML</abbr> powers the web.</p>

Example (result)

HTML powers the web.
