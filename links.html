Links, Images, Video & Audio

This page reviews the tags used to connect pages and embed media: hyperlinks with <a>, raster images with <img>, and the <video> / <audio> elements together with their <source> children. All media files are real assets from the images/ folder of this project.

On this page

  1. <a>
  2. <img>
  3. <video>
  4. <audio>
  5. <source>

<a> — Anchor / Hyperlink

Definition

Creates a hyperlink to another page, an anchor within the same page, an external site, or a downloadable file.

Attributes

Attributes of <a>
AttributeRole
hrefThe destination URL or path the link points to.
targetWhere to open the link, e.g. "_blank" for a new tab.
relDescribes the relationship to the target; "noopener noreferrer" is a security best practice for target="_blank".
downloadTells the browser to download the linked file instead of navigating to it.

Example (code)

<a href="index.html">Back to Home</a>
<a href="https://www.w3.org/" target="_blank" rel="noopener noreferrer">
  W3C website (new tab)
</a>
<a href="images/sample.png" download>Download sample.png</a>

Example (result)

Back to Home

W3C website (new tab)

Download sample.png

<img> — Image

Definition

Embeds a raster or vector image in the page. It is a void (self-closing) element.

Attributes

Attributes of <img>
AttributeRole
srcPath or URL of the image file to display.
altText alternative shown if the image fails to load and read by screen readers.
width / heightReserve space for the image before it loads, preventing layout shift.
loading"lazy" defers loading off-screen images until the user scrolls near them.

Example (code)

<img src="images/sample.png" alt="Generated sample gradient card"
     width="320" height="180" loading="lazy">

Example (result)

<video> — Video Player

Definition

Embeds a video with native browser playback controls. It can hold one or more <source> children for different file formats.

Attributes

Attributes of <video>
AttributeRole
controlsShows the browser's built-in play/pause/volume bar.
autoplayStarts playback automatically (requires muted in most browsers).
mutedStarts the video with no sound, allowing autoplay.
loopRestarts the video automatically once it ends.
posterImage shown before playback starts.

Example (code)

<video controls muted loop poster="images/sample.png" width="320">
  <source src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>

<audio> — Audio Player

Definition

Embeds a sound clip with native browser playback controls, using the same <source> mechanism as video.

Attributes

Attributes of <audio>
AttributeRole
controlsShows the browser's built-in play/pause/volume bar.

Example (code)

<audio controls>
  <source src="images/tone.wav" type="audio/wav">
  Your browser does not support the audio tag.
</audio>

Example (result)

2-second, 440 Hz tone generated with Python's wave module.

<source> — Media Source

Definition

Specifies one candidate media file for a parent <video>, <audio> or <picture> element; the browser picks the first one it can play.

Attributes

Attributes of <source>
AttributeRole
srcPath or URL to the media file.
typeThe file's MIME type, letting the browser skip formats it cannot play.

Example (code)

<audio controls>
  <source src="images/tone.wav" type="audio/wav">
</audio>
